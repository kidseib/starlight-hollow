Starlight Hollow 0.1.5-beta.1 - Windows x64 playtest

Extract this ZIP before running either file. Choose one:
- Starlight-Hollow-Portable.exe starts the game without installation.
- Starlight-Hollow-Setup.exe installs the game for your Windows user.

Windows 10/11 (64-bit) and a WebGL-capable graphics driver are required.
The game runtime and assets are included; no separate browser or Node.js
installation is needed. Spoken prompts depend on a local Windows English
speech voice. Subtitles are available if speech is unavailable.

This preview is unsigned. Windows may show an unknown-publisher warning.

NEW IN THIS BUILD: SMOOTHER FRAMES AND SIX PLACES TO WORK OUT
- The islands should feel lighter on older laptops and integrated graphics:
  scenery that never moves is now batched, far islands are put away, and
  resolution settles itself down when a scene stays slow and back up when it
  recovers. Please note the frame rate before and after if it still struggles.
- Six places now open only when a child works something out, with no menu:
  the Sleepy Bramble (read "moss" in Letterleaf Grove), the Lily Crossing
  (count the lilies in Tallybrook Falls), the Listening Path (match the croak
  in Storysong Glade), the Sky Stair (copy the pattern in Pattern Peaks),
  the Great Shell (answer five in Pebblecount Cove), and the Moonword (say
  "moon" in Lantern Hollow).
- Wrong answers never fail: the stone flickers, Pip repeats the hint, and the
  wrong choices dim one at a time until the answer is reachable. A solved
  place stays solved when the game is closed and reopened.

PLAYTEST CHECKLIST
- Launch both editions, then close and reopen to confirm progress survives.
  Check the installer's Start menu shortcut and uninstall too.
- At each of the six places, try a wrong answer first, then the right one.
  The bramble and the moth curtain should stay open after a reload.
- In the Grove, check that the bramble opens into a small hidden pocket with
  a seat and flowers, not onto bare grass.
- Walk the meadow in the opening view and around the Star Tree portal, then
  note whether movement feels smoother than 0.1.4. Press F3 if present, or
  open the console, and read window.__starlight.perf for draw calls.
- Check that old saves still load, spoken prompts still play, and Calm motion
  still softens the animations.
